# Exe

Personal photo gallery web app — a gallery with favorites and memories
views, built as a single-page React app.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- lucide-react icons

## Run it

```bash
npm install
npm run dev
```

```bash
npm run build   # production build
npm run preview # preview the build
```
